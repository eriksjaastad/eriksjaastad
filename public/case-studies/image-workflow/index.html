Image Workflow

Seven months turning a manual image review and cropping job into a Python pipeline. 313 commits, eight stages, used in real client work.

The problemWhat I builtHow it grewWhat came next

The problem

A high-volume content workflow ran on people: every image reviewed by hand, cropped by hand, sorted by hand. I built Image Workflow to automate it end to end, so a person only makes the calls a person has to make.

The work was for a confidential client, so there are no screenshots and no link to the code. This page describes the engineering only.

What I built

  • A batch image-processing pipeline in Python: automated cropping, grouping, selection staging and delete staging across large image sets.
  • A custom desktop review tool for fast human-in-the-loop triage of what the pipeline produced.
  • Dataset preparation for model training.

The pipeline is eight numbered steps, run in order on each project. The bar under each is how much code it took.

  1. 00Start a project780 lines
  2. 01AI-assisted review2,551 lines
  3. 02Crop and group2,779 lines
  4. 03Sort3,228 lines
  5. 04Check282 lines
  6. 05Compare folders803 lines
  7. 06Find duplicates873 lines
  8. 07Finish a project665 lines

About 12,100 lines across the eight stages, with 65 test files behind them.

How it grew

Most of it was built in two fast stretches, late September and October 2025 (175 commits that month alone), then a push in December. After that the commits thin out to a handful a month.

What came next

Image Workflow has since been retired, replaced by PickKit, a newer tool.
